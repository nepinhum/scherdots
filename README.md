# scherdots

Minimal, developer-oriented Hyprland dotfiles inspired by Kanagawa Wave.

There is nothing unnecessary. Just plain (very plain) configuration files.

## Stack

- **Compositor:** Hyprland (Lua)
- **Session manager:** UWSM
- **Terminal:** Kitty
- **Shell:** Zsh + Oh My Zsh
- **Status bar:** Waybar
- **Launcher:** Rofi
- **Notifications:** Mako
- **Wallpaper:** Hyprpaper
- **File manager:** Dolphin
- **Color scheme:** Kanagawa Wave

## Environment

Primarily maintained on EndeavourOS (Arch Linux).
